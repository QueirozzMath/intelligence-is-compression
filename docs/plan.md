# Plano de implementação

1. Preparar a estrutura, configuração reproduzível, carregamento/limpeza e testes das primitivas matemáticas.
2. Implementar compressão, NCD, modelos de n-gramas e utilitários de visualização.
3. Implementar os experimentos 0–8 como etapas independentes, com CSVs antes das figuras.
4. Exportar os dados derivados usados pelas animações sem números escritos à mão.
5. Implementar as cenas A1–A4, B1–B6 e C1–C3 em ManimGL e os comandos de renderização.
6. Executar testes e o modo rápido de ponta a ponta; conferir o manifesto de entregáveis.
7. Documentar resultados realmente produzidos, limitações, roteiro de slides e animações.

O modo rápido reduz bytes, artigos, ordens e reamostragens, mas percorre o mesmo código do modo completo.
